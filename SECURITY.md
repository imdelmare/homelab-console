# Security Policy

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** flow in the Security tab. Do not
open a public issue containing exploit details, credentials, private inventory,
or operator data.

Include the affected commit, component, impact, reproduction steps, and any
suggested mitigation. Reports concerning bypasses of the execution core,
approval consumption, authentication, redaction, or target allowlisting are
treated as high priority.

## Supported version

Security fixes currently target the latest commit on `main`. This project is
under active development and has not yet declared a stable release series.
