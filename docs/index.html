A control plane, not a remote shell ​

Homelab Console is designed around one constraint: an AI agent should be useful without becoming an unbounded administrator. The tool catalog contains named, typed capabilities instead of arbitrary commands, URLs, or provider payloads.

Use this manual to understand the trust boundaries, deploy your own instance, connect an MCP client, and extend the provider catalog without weakening the execution contract.
