A diagnosis, not a science project.

An illustrative governed workflow for a common homelab failure.

Incident - Home Assistant stopped responding
  1. Ask locally. “Why is Home Assistant down?”
  2. Collect evidence. A typed status tool reports the service unreachable.
  3. Follow the dependency. Proxmox reports the declared LXC is stopped.
  4. Propose, never assume. The reasoning layer identifies one exact start operation; a governed client requests it.
  5. Verify. After operator approval, the console starts the LXC and checks health again.

Small, imperfect, safely constrained.

Local models can be useful because they never receive direct infrastructure authority.

Security Properties
  • No generic remote execution. No arbitrary shell or SSH capability.
  • No raw provider access. Every endpoint and target is bounded.
  • Single-use approvals. Write consent is input-bound and expires.
  • Central redaction. Sensitive output is stripped before it leaves the core.
  • Structured evidence. Invocations, outcomes, and task history remain auditable.
