Five planes. One core.

Each layer has a distinct job and a deliberately limited trust boundary.

Control Plane
01

The canonical state

Inventory, identities, tasks, approvals, configuration, and a durable audit trail.

Tool Plane
02

Narrow by default

Explicit, typed capabilities instead of arbitrary shell, SSH, HTTP, or raw APIs.

Model Plane
03

Reasoning without privilege

Models receive bounded, redacted context and never hold infrastructure credentials.

Watcher Plane
04

Detect, deduplicate, report

Scheduled read-only observations create incidents and tasks without executing fixes.

Safety is architecture.

Agents can request actions. Only the operator can authorize a write.

Security Properties
  • No generic remote execution. No arbitrary shell or SSH capability.
  • No raw provider access. Every endpoint and target is bounded.
  • Single-use approvals. Write consent is input-bound and expires.
  • Central redaction. Sensitive output is stripped before it leaves the core.
  • Structured evidence. Invocations, outcomes, and task history remain auditable.
